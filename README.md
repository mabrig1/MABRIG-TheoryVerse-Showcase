TheoryVerse is a digital theory catalogue and research software project. Its original documentation describes a local PDF reader, consent-based conversation tools and a bounded AI/research gateway. Proposed theories are conceptual frameworks, not established scientific laws. This showcase does not establish independent verification of deployment or live AI capabilities.

## Reproduce the example

```sh
python demo/catalogue.py
python -m unittest discover -s demo -v
```

Python 3.10+; no dependencies or keys. The example demonstrates searchable metadata, explicit epistemic status, classification and validation using fictional records. It does not perform AI inference, read private documents or validate scientific theories.
