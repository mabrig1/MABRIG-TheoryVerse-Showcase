# Engineering case study: TheoryVerse

## Problem
Knowledge platforms must organize concepts and documents while protecting unpublished intellectual work and distinguishing hypotheses from established evidence.

## Design approach
Separate catalogue metadata from restricted documents. Make epistemic status explicit, keep human interpretation central, and obtain consent before external processing.

## Portfolio evidence
The independent example uses fictional concept records and demonstrates transparent catalogue filtering. It does not contain original theories, perform AI inference, read private documents or establish scientific validity. The product capabilities described in original documentation are not independently verified as deployed here.

## Interview topics
Knowledge representation, search, metadata validation, access boundaries, consent, document handling and automated tests.
